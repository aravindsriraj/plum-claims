# Plum — Health Insurance Claims Processing System

AI-powered claims adjudication: members upload medical documents, the system
verifies them, extracts structured data with a vision model, and decides
APPROVED / PARTIAL / REJECTED / MANUAL_REVIEW against a JSON-defined policy —
with a complete audit trace for every decision.

**Design principle: LLMs for perception, code for judgment.** Gemini 3.6 Flash
reads documents & invokes policy tools via a ReAct sub-agent; deterministic Python applies policy arithmetic. See `docs/ARCHITECTURE.md`.

## Quick start (local, 2 commands)

Prerequisites: Docker Desktop, and optionally a `GEMINI_API_KEY` (enables
vision extraction for real document uploads; without it, simulation-mode
claims still work).

```bash
export GEMINI_API_KEY=your_key_here   # optional but recommended
docker compose up --build
```

Then open **http://localhost:3000** — submit a claim, upload documents
(images/PDF), watch the live pipeline progress, and inspect the decision and
full processing trace.

Sample documents to upload are generated by:

```bash
backend/.venv/bin/python scripts/generate_mock_docs.py
# -> scripts/mock_docs/{prescription_rajesh.jpg, bill_rajesh.jpg, blurry_bill.jpg}
```

## Without Docker

```bash
# Backend (Python 3.12+)
cd backend
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
GEMINI_API_KEY=your_key .venv/bin/uvicorn app.main:app --port 8080

# Frontend (Node 22+), in another shell
cd frontend
npm install && npm run build && npm run start   # http://localhost:3000
```

## Deploy (Cloud Run)

```bash
export PROJECT_ID=your-gcp-project REGION=asia-south1
gcloud config set project $PROJECT_ID
gcloud services enable run.googleapis.com artifactregistry.googleapis.com cloudbuild.googleapis.com
gcloud artifacts repositories create plum --repository-format=docker --location=$REGION

# Backend
gcloud builds submit --tag $REGION-docker.pkg.dev/$PROJECT_ID/plum/backend ./backend
gcloud run deploy claims-api --image $REGION-docker.pkg.dev/$PROJECT_ID/plum/backend \
  --region $REGION --allow-unauthenticated --set-env-vars GEMINI_API_KEY=$GEMINI_API_KEY

# Frontend (point at the deployed backend URL)
BACKEND_URL=$(gcloud run services describe claims-api --region $REGION --format='value(status.url)')
gcloud builds submit --tag $REGION-docker.pkg.dev/$PROJECT_ID/plum/frontend ./frontend \
  --substitutions=_API_URL=$BACKEND_URL
gcloud run deploy claims-ui --image $REGION-docker.pkg.dev/$PROJECT_ID/plum/frontend \
  --region $REGION --allow-unauthenticated
```

(The frontend image is built with `API_URL` baked in via
`frontend/cloudbuild.yaml`:

```bash
gcloud builds submit --config cloudbuild.yaml \
  --substitutions=_API_URL=$BACKEND_URL ./frontend
```

)

## Layout

- `backend/app/contracts/` — Pydantic schemas (see `docs/CONTRACTS.md`)
- `backend/app/graph/` — LangGraph pipeline (7 components)
- `backend/app/rules/` — deterministic adjudication, financial engine, fraud,
  semantic tagging (clinical text → policy vocabulary)
- `backend/app/agents/` — LLM-facing agents + decision/explanation
- `docs/` — ARCHITECTURE.md, CONTRACTS.md, EVAL_REPORT.md
